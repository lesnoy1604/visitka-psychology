# Задание: сайт-визитка психолога Светланы Алексеевой в стиле «Function» (warm apothecary journal)

## Цель
Одностраничный сайт-визитка для частнопрактикующего психолога. Ощущение: спокойно, дорого, по-человечески тепло. Посетитель должен за 10 секунд понять, кто это, с чем она работает, и легко записаться на консультацию. Никакой «клиничности», никакой инфантильности, никаких стоковых улыбок.

## Стек
- Astro + Tailwind CSS v4, полностью статическая сборка (`npm run build` → `dist/`).
- Без тяжёлых JS-фреймворков. Минимум клиентского JS: только аккордеон FAQ (можно на `<details>`), мобильное меню и лёгкие появления при скролле.
- Все тексты, контакты и тарифы вынести в один файл `src/content/site.ts`, чтобы их можно было править без знания вёрстки.
- Деплой-ready для Netlify / Vercel / GitHub Pages.

## Дизайн-система
Главный источник: файл `DESIGN.md` в корне проекта (стиль Function с styles.refero.design). Прочитай его полностью до начала вёрстки и следуй ему. Ключевое:

**Цвета (CSS-переменные в `@theme`):**
- `--color-parchment: #fef9ef`: фон страницы. Чистый белый #fff запрещён везде.
- `--color-aged-paper: #f5eee1`: карточки, чередующиеся секции.
- `--color-warm-taupe: #d1c9bf`: тонкие линии и разделители.
- `--color-ink: #2a2b2f`: основной текст и заголовки.
- `--color-charcoal: #333333`: основной текст длинных абзацев.
- `--color-graphite: #515151`: подписи, второстепенное.
- `--color-accent: #b05a36` (терракота): только CTA-кнопки, eyebrow-надписи, активные состояния, штрихи иконок. Никогда не использовать для больших заливок и текста длиннее пары слов.

**Важно: акцент должен меняться одной переменной.** Сделай альтернативную тему «Ease Health» с акцентом `#0f3e17` (глубокий лесной зелёный). Переключение через атрибут `data-accent="green"` на `<html>`. Никакого второго акцентного цвета одновременно.

**Шрифты (сайт на русском, нужна кириллица!).** Оригинальные Financier Display и Ftbase платные и без кириллицы, поэтому используй замены с Google Fonts:
- Заголовки: **Cormorant Garamond** (500 roman + 400/500 italic). Если на крупных размерах выглядит слишком тонко, сравни с **Lora** и выбери лучший; покажи мне оба варианта скриншотами.
- Текст и интерфейс: **Inter** (300/400/600), letter-spacing `-0.023em` только для него.
- Мелкие eyebrow-метки: Inter 600 капсом, 12px (моноширинный шрифт не нужен).
- `font-display: swap`, подключить только нужные начертания и subset `cyrillic,latin`.

**Главный типографический приём:** в каждом крупном заголовке смешивать прямое и курсивное начертание в одной строке. Курсивом выделяется эмоциональное, «тёплое» слово, например: «Место, где можно *быть собой*», «С чем я *помогаю*», «Как проходит *работа*». Курсив только в заголовках от 34px. Никогда не курсивить целые предложения, кнопки и основной текст.

**Шкала:** hero 80–88px (на мобильном ~44–52px, через `clamp()`), заголовки секций 45px, карточки 34px, основной текст 16–18px, line-height 1.5.

**Формы:** карточки radius 24px, кнопки 40px, теги и поля ввода pill (9999px). Прямоугольные кнопки запрещены. Тени почти не использовать: глубина создаётся переходом parchment → aged-paper → taupe-линия. Разрешённая тень для «парящих» элементов: `rgba(42,43,47,0.1) 12px 32px 80px 0`.

**Сетка:** max-width 1280px, внешние отступы 24–40px, между секциями 64–96px (на мобильном 48–64px). Секции мягко чередуют фон parchment / aged-paper.

**Иконки:** только контурные, stroke 1.5px, цвет ink или акцент (например, Lucide). Никаких цветных и заливных иконок, никаких эмодзи.

## Анимации
Сдержанно: плавное появление секций (opacity + translateY 12px, 400–600ms, ease-out), мягкий hover у кнопок и карточек. Уважать `prefers-reduced-motion`. Никакого параллакса, никаких счётчиков цифр.

## Технические требования
- Адаптивность от 360px до 1920px, mobile-first. Проверь 375, 768, 1280, 1440.
- Доступность: семантические теги, один `<h1>`, alt у фото, видимый focus-ring (`0 0 0 3px` акцентом с 20% прозрачности), контраст текста не ниже WCAG AA. Проверь, что белый текст на терракотовой кнопке проходит AA.
- SEO: title «Светлана Алексеева — психолог», description, Open Graph (картинка 1200×630 в стиле сайта), `lang="ru"`, favicon, schema.org `Person` + `ProfessionalService` (с ценами из тарифов).
- Ссылки: телефон через `tel:`, WhatsApp через `https://wa.me/`, Telegram через `https://t.me/`, почта через `mailto:`.
- Без сторонних трекеров и аналитики по умолчанию. Для сайта психолога это вопрос доверия.
- Lighthouse: Performance, Accessibility, Best Practices, SEO не ниже 95 на мобильном. Картинки в AVIF/WebP через `astro:assets`.
- Страница `/privacy` с шаблоном политики конфиденциальности по 152-ФЗ (с пометкой TODO на юридическую проверку).

2. Сделай страницу-«витрину» `/styleguide`: цвета, типографика (с примерами смешанного курсива), кнопки, карточки тарифов, поля. Покажи мне и дождись подтверждения.

4. Прогони Lighthouse и проверку на мобильном, исправь проблемы.
5. Напиши README: как запустить, где менять тексты, контакты, тарифы, фото, цвета и акцент (терракота ↔ зелёный), как задеплоить.

## Чего избегать
- Чистый белый фон, холодные серые, синий «медицинский» цвет.
- Стоковые фото с рукопожатиями, мозгами, пазлами, бабочками и деревьями из людей.
- Градиентные кнопки, тени на всём подряд, скругления меньше 24px у карточек.
- Второй акцентный цвет.
- Тексты вида «Я помогу вам решить все проблемы!»: тон спокойный, без обещаний.
